# 抖音参考库（douyin_refs）

采集时间：2026-11-24
采集方式：抖音网页版，在当前登录账号「扬之昱🍀」状态下用浏览器直接读取页面（非第三方接口、非搜索转述）。
用途：**只作风格与比例参考库**，本目录不参与程序运行，不被 `build.ps1` 打包。

## JSON 字段

```
accounts[].nick / douyin_id / profile_url
accounts[].follows / fans / likes / works_total / ip / age / gender
accounts[].style          风格描述（人读）
accounts[].covers[]       本地封面文件名 + 备注
accounts[].works_sampled  本次抓到的条数
accounts[].works[].id     视频 ID（拼 https://www.douyin.com/video/<id> 可直接打开）
accounts[].works[].text   卡片文本（含点赞数与话题标签）
measurements              图像比例（方法、误差、已知缺失项）
palette                   封面取色
usage_note                使用边界
```

## 测量说明（重要：别当实测数据用）

- 比例取自封面像素目测，受**镜面自拍广角 + 约 8cm 高跟 + 平台滤镜**影响，误差约 ±10%。
- 小桃全部封面**头部在画面外**，头身比无法计算；身高体重两个号简介都没有，库里留 `unknown`，没有填猜测值。
- 已测：小桃裙摆下沿到鞋尖 ≈ 画面高 0.58，腰线到鞋尖 ≈ 0.79。

## 使用边界

真人照片只做**穿搭公式、配色、体型比例**的参考。若据此生成桌宠形象，脸部需原创化处理，不做本人肖像复刻。

## 如何更新

浏览器打开账号主页，向下滚动加载后，读取 `ul[data-e2e="scroll-list"] li` 内的 `a[href*='/video/']`，即可追加新条目（该方法已排除页面底部推荐位的混入）。
