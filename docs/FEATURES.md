# 功能手册

按「你会怎么用」来组织，而不是按代码模块。

## 1. 第一眼

桌宠是透明置顶窗口，站在桌面右下角那片空地上。第一次运行会出现一个简短气泡自我介绍，之后进入 idle 呼吸状态。

- 拖动任意位置都能挪她（透明区也算，窗口是整块的）。
- 双击/单击身体会触发摸摸头，气泡回应一句。
- 右键出菜单：聊天、语音、天气、新闻、动作、喂食、散步、睡觉、跟随鼠标、形态、换装、大小、音色、置顶、音效、碎碎念、主题。

## 2. 托盘图标（日常入口）

| 操作 | 结果 |
|---|---|
| 左键单击 | 显示 / 隐藏桌宠 |
| 右键 | 菜单：主题 / 打开控制面板 / 显示·隐藏 / 隐藏桌宠 / 自主行动 / 静音模式 / 退出程序 |

> v2.9.3 修掉一个坑：之前右键也会触发「显示 / 隐藏」，导致右键一次她消失、再右键一次又回来。

## 3. 养成

- 四项数值：饱食度、心情、亲密度，都随时间自然衰减。
- 零食四种：白米饭 10、小鱼干 20、鲸鱼奶茶 25、蓝莓蛋糕 30 金币。
- 金币来源：打工任务结算、番茄钟完成、偶尔自己「捡到」。
- 频繁戳（1 秒 7 次以上）只会得到一句抱怨，不再刷好感。

## 4. 打工

每个任务有金币/经验成本与耗时，点「开始」后进入进度条。清理类任务只处理临时目录，不会碰你的文档。

## 5. 定时任务与提醒

- 定时任务里的专注计时可设时长与轮数，结束后结算金币并播报。
- 喝水提醒默认 45 分钟、久坐提醒默认 60 分钟，间隔可在设置里改。
- 22 点休息提醒开启后，夜间活动量自动降低（走路变少、语速变慢）。

## 6. 聊天

面板「聊天」页是气泡流 + 输入框；桌宠头上也会弹气泡。

AI 后端三选一：

| 后端 | 场景 |
|---|---|
| OpenAI 兼容接口 | 填 endpoint / model / api_key |
| 本地 llama.cpp | `runtime/` 放好运行时与 `.gguf`，勾「本地大模型」 |
| Ollama | 已装 Ollama 时直接连 `127.0.0.1:11434` |

没网时走「没接上线」兜底话术，不会卡死在请求上。

## 7. 语音

1. 面板「语音人格」选方言人格（川渝软妹、粤语、东北、日语腔等 8 种）。
2. 「音色」子菜单选 `温柔少女` / `元气少女` / 关——前两档是从真人配音样本反查出来的 pitch 档位。
3. `Ctrl+Alt+V` 语音说一句。先说唤醒词（`大肥鱼` / `你好，大肥鱼` / `你好，<角色名>`），她回「在呢，说吧」并自动接听下一句。

## 8. 静音模式

默认开启。含义：**没任务时不吵**。

| 场景 | 出声吗 |
|---|---|
| 闲聊、碎碎念、天气/新闻播报、自主行动台词 | 否（只出气泡） |
| 对话回复、投喂、摸摸头、定时任务结束 | 是 |

托盘「静音模式」可关；想彻底没声音就把语音总开关关掉。

## 9. 桌面维护

- **满屏跑**：撞到桌面图标会把图标「碰掉」，然后慌张地一个个摆回原位。
- **擦桌面 / 做家务**：文件整理动作动画，不动真实文件。
- **清理垃圾**：扫描临时目录与缓存，列清单后确认再删。

## 10. 安全体检

分项检查：启动项、防火墙状态、系统补丁、账号风险、硬盘余量。只读检查 + 本地建议，不做自动修复，不会改系统设置。

## 11. 主题与外观

- 三档：跟随系统（读 `AppsUseLightTheme`）/ 浅色 / 深色。
- 面板是 macOS 风格：左侧侧边栏 12 项，右侧内容区，顶部标题与版本号。
- 形态：成熟 / 萝莉；皮肤：默认女仆、长发女仆、JK、成熟、汉服等（皮肤按形态过滤显示）。
- 大小：小 0.7 / 中 1.0 / 大 1.35。

## 12. 更新

面板「设置」里「检查更新」或启动 6 秒后静默检查一次。发现新版本弹「下载并安装」，下载带进度与 SHA256 校验，装完自动重启。

## 常见问题

**Q：透明处拖动会误触，正常吗？**
正常。窗口是整块矩形，透明区域没有做点击穿透（做穿透要靠硬边蒙版，会带锯齿与裁边）。

**Q：为什么换皮肤后脸不太一样？**
不同皮肤来自不同批次生成，正在统一重绘同一张脸。

**Q：语音唤不醒？**
目前唤醒词识别在按下 `Ctrl+Alt+V` 之后生效，不是常驻监听。

**Q：本地模型占内存？**
拔电（笔记本电池供电）时会自动暂停本地模型，插回电按配置恢复。
