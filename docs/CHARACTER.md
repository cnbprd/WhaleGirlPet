# 角色设定档案 · 溟月（鲸鱼娘）

本项目所有立绘、表情与动作素材，都以本档案为唯一身份来源。二次创作、替换素材、做梗图或衍生桌宠时，请先读这份档案，再动素材——这是解决「每个动作脸不一样」的根本办法。

## 3. 视觉锚点（改动即视为换角色）

1. **发**：深蓝（发根）→ 亮青（发梢）的渐变长发，发量厚、微卷、过腰。
2. **耳**：鳍状尖耳，左右各一对外展鳍膜。
3. **额**：正中小颗蓝宝石。
4. **眼**：白色瞳孔 + 细长上挑的杏眼；眼下有淡淡泪痣/腮红。
5. **脸**：冷感、窄下颌、几乎不笑（对应「富江式面孔」的既有设定）。
6. **尾**：鲸鱼尾鳍从腰后伸出，深蓝尾身、亮青尾尖；默认皮肤下位于身体右侧。
7. **服装（默认皮肤）**：深藏青女仆裙 + 白色蕾丝围裙 + 领口蓝色鲸鱼胸针 + 胸前白色鲸鱼刺绣 + 围裙左下角鲸鱼标 + 黑色玛丽珍鞋。

| 类别 | 数量 | 路径 | 说明 |

立绘规格：高度统一 512 px，宽度随透明边裁切自适应（脚本按 alpha 边界裁，不要手动拉伸），RGBA 透明底。

## 5. 母版与派生

- 身份母版：`assets/_matting/sheet-v2.png`（三视图，正/侧/背横排，统一脚底基线）。
- 派生规则：以母版为参考生成任意姿态，**只改姿势、表情、场景**，不改第 3 节任何一个锚点。
- 派生后处理：`tools/derive_sheet.py` 负责裁透明边、缩放到 512 高、生成与原图并排的对比图。
- 校验：派生图 `alpha_min` 必须为 0（真透明），否则视为未准出。
