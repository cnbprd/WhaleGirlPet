# 鲸鱼娘桌宠 v3.0.11：关键帧动画引擎（档 A）

一句话：把 8 个代码动作从「手写公式抖动」换成「轨道 × 关键帧 × 缓动曲线 + 事件点」，
**不改任何素材**，动作立刻从匀速跳变成有起势、有惯性、有落地反馈。

## 一、之前是什么样

`pet_window.py` 里 8 个动作（crab / floatstep / trot / look / eatrice / tumble / brawl / hop）
全是 `_tick` 里按 state 分支手写的位移公式，典型长这样：

```python
bob = -abs(math.sin(phase * 3.14)) * 90 * scale   # 匀速三角函数，起落一样快
```

问题肉眼可见：起跳没有蓄力、下落不收力、落地没有一顿；摔跤是整图旋转，没有压扁回弹。

## 二、现在是什么样（`app/anim_engine.py`）

### 四个基本件
- **缓动**：`linear / in / out / sine / back / bounce / elastic`
- **Track**：一条通道的关键帧序列 `(时间, 值, 缓动)`，相邻关键帧之间插值
- **Pose**：一帧的完整姿态 `bob / rot / sx / sy / alpha / dx / dy / flip`
- **Clip**：`tracks + duration + loop + events`，即一个完整动作

### 六个通道
位移（bob / dx / dy）、旋转（rot）、缩放（sx / sy）、透明度（alpha）、朝向（flip）。
`flip` 没有轨道的动作返回 `None`，不会把换装/镜像状态强行清掉。

### 事件点（动作里的"骨头声"）
动作可埋时间点，播放时按帧回调：
- `tumble` 在 1.35s 埋 `land`、1.9s 埋 `recover`
- `hop` 三段跳各埋一个 `land`（0.34 / 1.02 / 1.70s）

`pet_window._on_anim_event` 收到 `land` 就播 `step` 音效（priority=1）并补一帧 1.5px 的下沉，
落地那一下有声音也有"顿感"。事件用 `_fired` 集合去重，同一轮同一事件只响一次；
循环动作回卷时清空，下一轮再响。

### 8 个动作的曲线要点

| 动作 | 时长 | 关键设计 |
|---|---|---|
| crab 螃蟹步 | 0.63s 循环 | 小幅上下 + 左右歪，`flip` 保持原朝向 |
| floatstep 漂浮踏步 | 2.09s 循环 | 正弦慢起落，峰值 -7.4px，飘着走 |
| trot 小跑 | 0.63s 循环 | 双峰快步，比原来更碎更快 |
| look 左右看 | 2.40s 循环 | 头身反向微倾 + 整体镜像左右扫（`flip` 通道） |
| eatrice 吃白饭 | 1.20s 循环 | 低头 + 微下沉，幅度克制不夸张 |
| tumble 摔一跤 | 2.20s 单次 | 前扑 → 腾空（bob 峰值 -25.9 / rot 22°）→ 落地压扁（sy 0.755）→ 回弹站起，两个事件点 |
| brawl 打闹 | 0.98s 循环 | 左右甩 + 蹬腿，`sy` 随幅度压伸 |
| hop 蹦蹦跳 | 2.04s 单次 | 三段跳，起跳用 `out` 缓动（起势快），落地压扁再弹，落点各一次脚步 |

## 三、怎么关掉

设置 → 桌宠行为 → **「动作用关键帧动画引擎」**（默认开）。
关掉立刻回退到旧的手写公式，方便对照。配置键 `config["anim_timeline"]`，默认 `True`。

## 四、实测记录

**数值采样**（`tools/test_anim_engine.py`，60fps 逐帧推进）

| 动作 | 采样结果（时间, bob, rot, sx, sy） | 事件点 | 末帧 done |
|---|---|---|---|
| crab | 0→-1.1→-3.0 缓慢下沉 | 无 | False |
| floatstep | 峰值 -7.4 | 无 | False |
| trot | 双峰 -2.2/-1.6 | 无 | False |
| look | rot 0→3.0（右倾）→ -3.0（左倾） | 无 | False |
| eatrice | 低头 0→4→7.5 | 无 | False |
| tumble | bob 峰值 -25.9 / rot 峰值 22° | `land`、`recover` | True |
| brawl | sy 0.94~1.05 压伸 | 无 | False |
| hop | 起跳 -91.6 → 落地 -2.7 → 二跳 -66.0 | `land` × 3 | True |

> 首轮实测 bug：事件点每帧都被判定"满足"，tumble/hop 各刷出几十条 `land`。
> 原因是去重条件依赖已被 `pop_events()` 清空的队列。加了独立的 `_fired` 集合后重测，
> 修正为 tumble 2 条、hop 3 条，与定义一致。

**状态机集成冒烟**（`tools/test_pet_timeline.py`，真 `PetWindow` + offscreen）

```
[hop]    t=0.33 bob=-91.6 sy=1.047 → t=0.66 落地 bob=-3.5 → t=1.32 二跳 -2.7 → 2.31s 回 idle，tl 停播
[tumble] t=0.33 rot=16.3 → t=0.66 rot=20.8 → t=0.99 落地 sy=0.755（压扁）→ 回正 → idle
[crab]   bob 缓慢 -1.1→-3.0，flip 交替，持续循环不被打断
[look]   flip True（右）→ False（左）→ True，视线扫动正常
关开关后：tl.playing=False，旧公式 bob=-14.0
```
