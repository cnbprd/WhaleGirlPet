## v3.0.6

这一版只干一件事：**修掉两个你亲眼看到的 bug**。

### 1. 启动后那个女仆装大肥鱼一直卡在桌面上

现象：装完启动，中间那个女仆装（启动画面）不消失，跟右下角的学生装桌宠同时挂在桌面上；那个窗口还不吃点击、拖不动，重启才没。

根因不是「定时器没跑」，而是**淡入和淡出在打架**：

```python
# 修复前的 _tick（每 24ms 一次）
if self._fade < 1.0:                 # 淡入逻辑
    self._fade = min(1.0, el / FADE_IN)   # 每帧无条件把 _fade 拉回 1.0
if self._done and ...:               # 淡出逻辑
    self._fade -= 0.075                   # 每帧只减 0.075
```

`_fade` 每次先被重置成 1.0、再减 0.075，于是**永远停在 0.925**，`_fade <= 0` 的关闭分支一次都进不去 —— 窗口就一直挂着。实测探针数据：启动后 1 秒 `_fade=1.000`，3/6/9 秒都是 `0.925` 一动不动，而 `_tm.isActive()=True`、`remainingTime()` 在 0↔9 跳动（定时器其实一直活着，白跑了 200 多次）。

修法：淡入只在还没收到 `finish()` 时做（加 `not self._done`）。

| 项 | 实测 |
|---|---|
| 修复后 `_fade` 轨迹 | 1.000 → 0.925 → … → −0.050，走到关闭分支 |
| 修复后窗口状态 | `closing=True`、`visible=False`、`IsWindowVisible=0`（系统层面确实不可见） |
| 定时器 | `isActive()` 关闭后为 False，不再每 24ms 空转 |

顺手加了三道兜底（万一以后再出别的原因卡住）：
- 15 秒硬超时，到点不管什么状态都强关；
- 关闭时先用 Win32 `ShowWindow(SW_HIDE)` 直接藏窗口，绕过 Qt 事件循环（事件循环真死了也能藏）；
- 启动流程 `step2/step4` 包 try/finally，中途抛异常也保证把这个浮层收掉；
- 新增 `runtime\startup.log` 记录启动时间线，下次再卡能直接看出卡在哪一步。

> 你机器上那个还卡着的实例是 3.0.5 的，新版本装上重开就没了；这次不会再有第二个。

### 2. 不定时刷新文件资源管理器（桌面图标被挪动）

现象：用着用着资源管理器自己刷一下，桌面图标位置变了。

根因：满屏跑时「撞到东西就把附近图标撞散、2.6 秒后复位」是**真的动系统桌面图标**——通过 `LVM_SETITEMPOSITION` 改 SysListView32 里每个图标的坐标。每改一次坐标资源管理器就重排一次，看起来就是桌面刷新。触发链路：

```
20 秒一次自动行为抽签 → 抽到 run（权重 10%）→ 满屏跑 6 秒
→ 随机 3~6 秒后撞一次 → 挪 3 个图标 → 2.6 秒后复位
```

也就是平均 3~6 分钟你就会被它刷一次桌面。

修法：**默认不碰真实图标**。

| 项 | 说明 |
|---|---|
| 默认行为 | 只撞、只喊疼、只出气泡，一个真实图标都不动 |
| 想玩真格的 | 「设置 → 桌宠行为」新增开关「满屏跑时撞乱桌面图标」，勾上才恢复原来的挪图标玩法 |
| 配置项 | `allow_icon_scatter`，默认 `False` |
