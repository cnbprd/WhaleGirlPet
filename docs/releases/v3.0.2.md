## v3.0.2

### 修复
- **下载安装包的人用不了本地模型**：v3.0.1 的 Release 安装包是 70.8MB，比本地打的 93.3MB 少 22MB——因为 `runtime/` 整个被 `.gitignore` 排除，CI 拿不到 `runtime/dafeiyu` 里的推理引擎（`dafeiyu-server.exe` + `llama-server-impl.dll` 等 52 个文件），装完只能走云端 API 或内置台词。
  这一版把引擎（62.9MB，最大单文件 10.9MB）纳入仓库，CI 打包时 `installer/whale_pet.iss` 的 `Source: "..\runtime\dafeiyu\*"` 就能取到，安装包补回本地离线能力。
  `runtime/models`（15.48GB 的 gguf）、`runtime/_dl`（下载缓存）、日志与配置备份仍然排除，不会进仓库。

### 说明
- 模型仍然不随包分发（体积与授权都不合适）。装完要离线聊，把 `.gguf` 拖到安装目录的 `copy_models.cmd` 上即可，引擎已就位，只缺模型文件。
- 仓库因此增加约 63MB，这是把二进制当源码托管的代价；如果以后要瘦身，得改写历史，不建议随意做。
