## v2.9.2

### 修复
- **摔一跤把立绘转成横躺**：翻滚动作的旋转角一路到 360°，整张立绘在屏幕上横着躺，已限到 22° 以内的失衡摆动，保留腾空与落地压扁。
- **右键托盘把桌宠藏了**：托盘点击事件不分按键一律切换显隐，右键弹菜单前先触发了一次隐藏，改为只有左键才切换。
- **说话太多太吵**：闲聊、天气、新闻、自主台词这类低优先级只出气泡不出声，对话回复与投喂拍照仍正常发声。
- **换装还播报**：换装动作不再播「等我换件衣服……」。
- **睡眠脸与尺寸不一致**：睡眠图是另一张圆脸，坐姿按图高缩放后又比站姿大一整圈，已按身份母版重绘并重排为画布高度 62%，与其他立绘同量级。
- **双屏下桌宠凭空消失**：边界钳制把窗口推到副屏且跟随鼠标时完全不钳，改为至少 65% 窗口留在主屏，跟随分支每帧也钳一次。

### 新增
- **真人音色提炼**：两段真人配音做 40ms 帧基频统计，用 Edge TTS 实测曲线反查音高，得到两个真人音色，端到端偏差 8.5Hz。
- **主题三档**：浅色 / 深色 / 跟随系统，托盘有主题子菜单，浅色下数值条清晰可读。
- **语音唤醒词**：支持「大肥鱼」「你好，大肥鱼」「你好，角色名」三种叫法，日常对话不会误触发。
- **形态切换静默**：切形态不再出声。
- **去蒙版真透明**：默认走真透明窗口，外扩 18% 活动余量并做补偿，起跳与翻滚不裁头。
- **面板改 macOS 风格**：顶部横排标签换成左侧列表侧边栏加右侧内容区，带胶囊选中态、标题栏与版本号。
- **面板数值条重做**：原来写死深灰色加字符方块，深色主题下糊成一片，改成按主题取色的色块条，低值标红。
- **立绘统一第一批**：新增角色母版规范文档，四套立绘按母版重绘替换，旧图备份保留。
- **去底工具修正**：PIL 13 的泛洪填充实测静默不生效，改为逐行游程加并查集自实现，自动识别黑底白底。
- **开源文档**：重写 README，新增 MIT 许可证与角色二创声明、更新日志、架构文档、功能文档、依赖清单。
- **发布通道**：网页上传始终塞不进文件，改为 GitHub Actions 在 runner 上打包并上传 Release。

### 已知不足
- 各皮肤立绘的脸仍有个别批次不一致，需要继续统一重绘。
- 形态与换装切换的果冻回弹过渡动画还没做。
- CI 产物不含本地模型运行库，所以安装包体积小于本地构建版。
