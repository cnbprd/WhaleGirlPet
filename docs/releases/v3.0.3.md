## v3.0.3

这一版把「本地模型装不装」这条链路补齐：安装时问一句，不装的人之后能在设置里按建议自己挑。

### 安装向导
- **第 4 问文案改成实话**：原来写"约 3–4GB，装完后台自动下"，与实际可选模型对不上（最轻 1.0GB、推荐 2.3GB、最重 4.4GB）。现在写「装完自动下，约 1–4.5GB；先不装也行，之后在「设置→自定义模型」里补」。
- **默认仍是「先不装」**，选「要，装一个」才在安装结束时写 `want_local_model.flag`，程序首次启动 4 秒后按本机显卡/内存挑模型并后台下载。

### 设置 → 自定义模型
- **修好「模型仓库」只显示一行的问题**：列表原来只给了最大高度、又被布局压扁，实测只露出 1 行，等于把仓库藏起来了。改成最小高度 168，现在一次能看到 3 行（★ 推荐那行不再是唯一可见项），其余滚动可选，双击一行即可下载。
- **整页改成可滚动**：内容比窗口高时滚动，不再把控件挤成一条缝。
- **状态文案说人话**：没有本地模型时不再显示"未找到模型或推理程序"，改成「还没装本地模型（不影响使用，聊天走云端或台词）」，并指向下面的仓库。

### 说明
- 模型清单与体积取自 `models_catalog.py`（HuggingFace 镜像实核）：Qwen3-4B 2.3GB（默认）、DeepSeek-1.5B 1.0GB（最轻）、DeepSeek-7B 4.4GB、GLM-4-9B 5.8GB。
- 「★」是本机推荐，按显卡显存与内存挑；你这台（GTX 1060 6GB / 31.9GB 内存）推荐 DeepSeek-R1-Distill-7B。
