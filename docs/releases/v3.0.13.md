# 鲸鱼娘桌宠 v3.0.13：游戏引擎式 2D 骨骼动画（骨架 + 蒙皮 + 动作剪辑）

先按你说的把**基础搭起来**：不做复杂编辑器、不做导出格式、不做多动作混合，
只把"能让动作动起来"的四个核心件立住，后面照着开源引擎的结构往上加。

## 一、四件套（`app/skeletal.py`）

| 组件 | 职责 | 本项目实现 |
|---|---|---|
| `Skeleton` | 骨骼树 | 9 根骨：`root → spine → head`，`root → thigh_l/r → shin_l/r → foot_l/r`；每根骨的角度**相对父骨**，世界角度沿链累加 |
| `Skin` | 蒙皮 | 8×20 顶点网格覆盖整张立绘；每个顶点绑 1–3 根骨 + 权重（腿区：大腿/小腿/脚按高度过渡；头颈：head/spine 过渡）；形变用线性混合蒙皮 LBS |
| `Clip` | 动作剪辑 | 每根骨一条角度关键帧轨道，复用 v3.0.11 的 `anim_engine.Track` 与 7 种缓动；支持循环与事件点 |
| `Player` | 播放器 | 播放/推进/循环回卷/事件去重（与 v3.0.11 时间轴同一套语义） |

渲染仍是"逐三角形仿射贴图 + 目标裁剪"，与 `rig.py` 共用 `_affine_from_tri`。

## 二、动作库（5 条剪辑）

| 动作 | 时长 | 内容 |
|---|---|---|
| `walk` | 0.78s 循环 | 左右腿交替 ±10°、抬腿相屈膝 22°、躯干 ±2.8°、头反向 ±1.8° |
| `run` | 0.52s 循环 | 腿 ±18°、屈膝 40°、躯干前倾 6° |
| `hop` | 2.04s 单次 | 蓄力下沉（屈膝 44°）→ 起跳伸腿 → 滞空 → 落地缓冲，1 个 `land` 事件 |
| `tumble` | 2.2s 单次 | 前扑屈膝 → 躯干反转 → 回正，`land` / `recover` 两个事件 |
| `breath` | 3.6s 循环 | 待机呼吸：躯干 3°、头 -1.8° |

**脚部自动补偿**：没写 `foot` 轨道的剪辑，自动把脚角设成 `-0.6×(thigh+shin)` 并限幅 ±25°，
鞋大致保持水平，不会跟着小腿整只翻过去。

## 三、实测记录

| 项 | 实测 |
|---|---|
| `render()` 单帧（8×20 网格，含抗锯齿） | 23.6 ms |
| `render()` 单帧（关抗锯齿） | **10.5 ms** → 96 fps 上限 |
| 走路三方案逐帧对比 | `docs/rig_walk_compare.png`：骨骼引擎 / 网格腿 rig / 条带 warp |
| 动作库出帧 | `docs/skeletal_v313.png`：walk / run / hop / tumble 各 4 帧 |

**这轮踩到的 4 个坑（都已修）**
1. `_rot()` 的枢轴有时传元组、有时传 `QPointF`，父骨链一跑就 `TypeError`
2. 测试脚本把 `QPixmap` 传给 `drawImage()`（要 `QImage`）→ 直接崩
3. 全身处处重绘 → 身上一层细横纹：因为微小角度让每格都变形。修法：顶点位移 **<0.8px 吸附不动** + 关掉三角形绘制时的抗锯齿（外扩 0.18px 已够消缝），副作用是极边缘轻微锯齿
4. 脚补偿过量（-0.9 倍无上限）→ 40° 屈膝时鞋被甩到腿侧。改为 **-0.6 倍 + 限幅 ±25°**

## 四、引用与出处（你要求的）

`docs/THIRD_PARTY.md` 已落地，README 也加了一段。要点：

- **Godot Engine 4.x**（`Skeleton2D` / `Bone2D` / `Polygon2D` 权重蒙皮），**MIT**：
  骨架树"每根骨落在起点 + 角度相对父骨"、整张 sprite 绑多骨、关节用权重过渡带——结构借鉴，代码自写。
  https://docs.godotengine.org/en/stable/tutorials/animation/2d_skeletons.html
- **Inochi2D**，**BSD 2-Clause**：开源 2D rigging（Live2D 替代），确认"网格 + 变形器/骨骼 + 参数驱动"的可行边界。
  https://inochi2d.com
- **未使用** Spine Runtime：许可要求产品每个用户自行持有 Spine Editor 授权、且再分发须附带许可，免费分发的桌宠不适合承担。Live2D Cubism SDK 同样专有，未用。

引擎代码里没有一行是从这些项目复制的；两份许可证都允许商用与再分发，本项目既不复制代码也不打包其二进制。

## 五、现在的边界（别把这版当 Live2D）

1. 素材仍是整张 PNG：**手臂、裙摆、尾巴、头发没有独立权重**，走路时它们跟着躯干整体动
2. 脚没有 IK：抬腿时脚离地，落地也没有"踩住地面"的约束
3. `run` 40° 屈膝下小腿明显拉伸（LBS 体积收缩）
4. 骨架比例是按 `default.png` 量的，换更宽的皮肤（如 hanfu 288px）会略偏，可用但未逐个标定
5. 目前只接了 `walk` / `run` 两个状态；`hop` / `tumble` 的剪辑已经写好，尚未接线（下一版）
