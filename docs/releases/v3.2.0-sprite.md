# v3.2.0-sprite 发布说明

状态：**已公开发布（tag `v3.2.0-sprite`，commit `a2ef92c`）；代码签名 `NotSigned`。** 24h 浸泡、17 卡可见、真实点击、安装器安装/卸载和资产校验均已通过；Release 资产已上传并下载核对哈希。

这一版把 2D 表情/动作卡面接进 3D：`expression/*` 与 `action/*` 共 17 张卡通过 UDP `card` / `card_ttl_ms` 显示；卡面由独立透明 overlay 窗口绘制，不再撑大主 3D 窗口的可点击区域。

## 1. 本版变化

- **独立卡面 overlay**：主 3D 窗口只保留模型像素 region；卡面在单独的透明、置顶、不可聚焦窗口里绘制，overlay 的 Win32 region 裁成卡面矩形。
- **点击穿透**：overlay 把卡面区域收到的左/右/中键事件转发给 z-order 下方第一个可命中窗口；主窗口在卡面位置返回 `HTTRANSPARENT`，模型位置仍是 `HTCLIENT`。
- **P1 manifest 解析**：`sprite_manifest::parseJson()` / `validateAtlasSize()` 独立纯解析，17 条夹具覆盖 1 个成功 + 16 个失败输入。
- **静态审计修复**：`ready` 状态、初始化失败清理、单实例互斥、`spriteReady` 门控、模型空指针保护、空 region/托盘降级。
- **打包**：便携 ZIP 和安装器都内置 `assets/2d_bridge`，安装后的 `whale3d.exe` 可直接显示卡面。

## 5. 已知限制

- overlay 输入转发主要覆盖左/右/中键按下与抬起，不保证 hover / 拖拽 / 滚轮逐像素转发到所有类型的下层窗口。
- 点击验收是在受控 z 序下完成：测试目标临时置顶，再让 3D 主窗口和卡面 overlay 回到目标上方；普通桌面窗口的 z 序仍需现场复核。
- overlay 创建失败时回退到旧的主窗口卡面路径，该路径没有跨进程点击转发能力。
- 卡面是屏幕空间装饰，不参与骨骼、服装替换或拖拽；只画一张卡，新卡覆盖旧卡。
- 只支持 Windows + OpenGL 3.3 core。
- 安装器和 exe 当前为 `NotSigned`；SignPath Foundation 已于 2026-11-27 拒绝（公开可见度不足），未使用付费 OV。
- 2D PyInstaller 冻结包未在本轮重新打包/启动回归；本版发布的是 3D sprite 链路。
