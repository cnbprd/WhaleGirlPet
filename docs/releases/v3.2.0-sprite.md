# v3.2.0-sprite（本地候选，未发布）

> 状态：**本地 Release notes 草稿，未创建 GitHub Release、未上传资产。**  
> 建议 tag：`v3.2.0-sprite`。不要覆盖现有 `v3.2.0-dev`。

这一版把 2D 表情/动作卡面真正接进 3D 渲染循环：3D 主循环右下角可以显示单张 `expression/*` 或 `action/*` 卡，卡面通过 UDP `card` / `card_ttl_ms` 触发；便携包和安装器都内置 `assets/2d_bridge`。

## 1. 本版变化

| 项 | 改动 | 实测 |
|---|---|---|
| 1 卡面接线 | 新增屏幕空间 `SpriteLayer`；`main.cpp` 初始化、UDP `card`/`card_ttl_ms` 接线、每帧 `update/draw`、窗口 region 扩展 | 日志 `Sprite layer: ready (...\assets\2d_bridge)`；真实 `AssetBridge.action('wave', 2600)` → `source=P_2D card=action/wave`；`expression/happy`、`action/wave` 可见 |
| 2 渲染修复 | 修 UV 子矩形缺失 `uUvRect`、模型遗留 culling、`stb_image` 与 GL 纹理原点导致的上下颠倒 | 强制 alpha 帧从整张图集小卡网格变为单卡；纯红 quad 证明位置正确；卡面正向、右下角约 127×220 |
| 3 图集与清单 | `assets/2d_bridge/atlas.png` 1024×512，17 张 1x 卡；`manifest.json`；离线 QA 与协议 fuzz | 图集 QA 17/17：`max_alpha_mae=0.0`、`max_rgb_mae=0.005`、`max_coverage_delta=0.0`；manifest 17 卡、0 error / 0 warning；协议 fuzz 通过 |
| 4 包与安装器 | `WhaleGirlPet.spec` datas 补 `assets/2d_bridge`；CI ZIP 打包补复制；版本资源 `3.2.0.0`；生成 sprite 便携包与安装器 | 安装器静默安装到临时目录 exit 0，安装后含 `assets\2d_bridge`，启动/卸载 exit 0 |
| 5 CI | 3D CI 只构建 exe/ZIP，不构建安装器、不自动发 Release；本版发布仍走本地打包 + 本地上传 | 3D CI 静态审计通过；本版未触发 `release-assets.yml` |

## 5. 已知限制

- 卡面是屏幕空间装饰，不参与点击、拖拽、骨骼或服装替换。
- 只画一张卡，最新卡覆盖旧卡；没有队列/动画。
- 卡面高度上限 220 px，宽度按 manifest 宽高比；极端窗口尺寸下位置和大小仍需看。
- 只支持 Windows + OpenGL 3.3 core；缺 GL 入口点时 sprite init 会失败，但不影响 3D 主体。
- 安装包未签名，SignPath 仍在审核。
- 24 小时未完成前，本版本按测试版看待。
