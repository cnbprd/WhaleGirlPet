# 鲸鱼娘桌宠 v3.0.10：天气卡片 + 鲸鱼娘安全管家

两个东西：天气资讯页终于像样了；加了一套自研的启发式安全扫描（**只报不杀**）。

## 一、天气资讯页

**新增「现在天气」卡片**
- 温度大字 + 城市·天气（例：`16°` / `郑州 · 晴`）
- 体感 / 湿度 / 风 / 降水概率 / 空气质量一行看全
- 今日最低~最高（例：`今日 3 ~ 21°`）
- 数据源与更新时间（例：`数据源：中国天气网　更新 20:18`）
- 新增「刷新天气」按钮，后台线程取数，不卡界面

**资讯框不再只有 3 行**
以前固定 86px，分类资讯只能看到几条还挤成一坨。现在撑满整页到底部（560px 页高时 323px），点分类按钮后标题一条条列清。

## 二、鲸鱼娘安全管家（v3.0.10 新增）

### 定位
**只读研判，只报不杀。** 不删文件、不隔离、不改注册表。真要处置交给 Windows Defender，由官方引擎判定与清理。

### 三层扫描核心（`app/guard_core.py`，纯 Python 零第三方依赖）

1. **PE 静态解析**：DOS/NT 头、节区表、每节香农熵、可写且可执行的节、入口点是否落在可写节、证书目录是否存在、编译时间戳是否在未来
2. **迷你规则引擎**：JSON 规则（正则 / 字符串 / 十六进制）× 作用域（文件内容 / 路径 / 命令行）× 权重与等级；内置 15 条（PowerShell 编码命令、certutil 解码、mshta/rundll32/regsvr32 远程加载、bitsadmin 下载、隐藏窗口链、临时目录启动、反射执行、持久化写入、RAT 关键字、勒索信特征、矿池地址…）
3. **持久化 + 进程审计**：Run/RunOnce（HKCU/HKLM/WOW6432）、启动文件夹、计划任务、服务、IFEO 调试器劫持，加上运行中进程的命令行——无文件攻击只在内存里跑，光查文件会漏

### 风险评分
单条最高分 + 线索数量轻加成（高危 10/条、中危 4/条，加成上限 30），0–100 分 → 高/中/低/提示。不用简单相加，避免"6 个低权重样本也堆到 100"。

### 实测（本机真实跑）
| 场景 | 结果 |
|---|---|
| 真机全量（Temp / 下载 / 桌面 / Public / AppData） | **244 个文件 + 132 个进程，4.8 秒，风险分 4（提示），1 条 info** |
| 构造样本目录（6 个假样本） | **6 条线索：H001 PowerShell 编码命令 38 分、H010 反射加载 30 分、H011 持久化写入 24 分…合计 68 分「高」** |
| Defender 交接 | 单文件 `MpCmdRun -Scan -ScanType 3 -File` 返回 `Scan finished. … found no threats.`（returncode 0） |
| 误报收敛 | 首轮 11 条 / 64 分（Firefox、pnpm 的正常 JS 被当勒索）→ 排除开发目录、`.js` 豁免 base64、勒索规则改勒索信特征后降到 4 分 |

### 报告
每次扫描落盘 `<数据目录>/reports/guard_<日期_时间>.md` 和同名 `.json`，面板可「导出报告」或「打开报告文件夹」。

### 面板
「安全体检」页拆成两块：上半仍是只读体检（Defender 状态 / 自启项 / 后门端口 / 可疑进程 / 更新病毒库 / 打开 Defender）；下半是安全管家：扫描一遍 / 交给 Defender 深扫 / 导出报告 / 打开报告文件夹 + 结果表格（等级 / 对象 / 原因 / 规则）+ 实时进度行。

## 边界说明（重要）
- 这不是杀毒软件：没有病毒库授权、没有脱壳与动态沙箱、没有内核级实时防护、不会替你清除。
- 它的价值是**把"可疑"讲清楚**：哪个文件、哪个启动项、为什么可疑、规则编号是什么，然后你决定是否交给 Defender。
- 自定义规则：把 JSON 放进 `<数据目录>/rules/guard/*.json`，字段 `id/name/level/weight/scope/kind/pattern/why`，同 id 覆盖内置规则。
