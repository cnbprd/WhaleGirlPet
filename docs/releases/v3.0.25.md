# v3.0.25（2026-11-26）

本版收四条：API 与本地模型路由分离、打工任务收进二级页、养成衰减调慢并在归零时主动讨要、
`anim.md` 第二阶段（表情脸补丁 + 伪口型）。

## 1. API 接入和本地模型不再抢路由

| 项 | 改动 |
|---|---|
| 新配置 | `llm_prefer_local`，默认 `False` |
| 语义拆分 | `llm_on` 只管“允许本地兜底”；`llm_prefer_local` 才表示“优先本地” |
| 路由 | 有 API key 且没勾优先本地 → 走 API；没 API / 勾了优先本地 → 走本地；两边都没有 → 明确提示 |
| 面板 | 复选框改绑 `llm_prefer_local`，文案“不勾 = 配了 API 就先走 API”；取消勾选不会关闭本地模型 |
| 失败兜底 | API 请求失败后单向切一次本地模型；本地也失败才出台词，避免来回踢皮球 |

之前只要本地模型可用，配了 API 也永远轮不到 API；现在“有 API 默认 API，本地只兜底”。

## 2. 打工任务变成「去打工」二级页

- 养成主页面只留「背包 / 零食商城 / 去打工」三个按钮，任务列表不再摊在下面。
- 点「去打工」→ 同一面板内 `QStackedWidget` 切到第二页：打工任务列表 + 「← 返回养成」。
- 托盘/菜单重新打开面板时默认回主页面；`open_task_page()` 仍可直接落到二级页。

## 3. 饱食 / 水分下降调慢 + 归零主动讨要

| 项 | 旧 | 新 |
|---|---|---|
| 饱食基础下降 | `0.30/分钟`（100→0 约 5.5h） | `0.12/分钟`（100→0 约 14h） |
| 水分比例 | 饱食的 60% | 饱食的 55%（100→0 约 25h） |
| 离线结算 | 最多补 6h | 不变 |
| 归零触发 | 受面板/任务/背包/状态栏冷却限制，口渴没有独立入口 | `critical_need(8)` 独立触发；面板开着只冒泡不抢窗口，任务中暂缓 |
| 讨要选品 | 从全部零食里随机 | 渴了优先水分高的饮品/水果（柠檬水、西瓜等），饿了优先饱食高的主食/肉鱼；背包里也按需求挑 |
| 冷却 | 600s | 普通 300s；归零级 180s |

## 4. `anim.md` 第二阶段：表情脸补丁 + 伪口型

### 表情脸补丁

- 新增 `tools/make_expression_patches.py`，从表情图裁出羽化椭圆脸补丁，贴到默认立绘同一张脸上；身体保持 idle，不再整张换身体。
- 共 6 个补丁：`angry / happy / idle / pat / shy / walk`。
- `sleep / eat / curious / sleepy` 是姿势表情（蜷坐、捧碗、托腮、捂嘴），保留整图换身体才合理。
- 合成结果按 `QPixmap.cacheKey` 缓存；1x/2x 各自加载，放大时仍走超采样。
- 目前对默认女仆和 JK 两张皮肤生效（两张脸坐标一致）；其他皮肤还没有对应锚点，维持旧行为（不换图，只轻微一顿）。

### 伪口型

- `AudioManager.play_file(..., speech=True)`：TTS 播放时用 `QAudioDecoder` 解 MP3，按 24ms 缓冲算 RMS 包络。
- 包络写到 `<音频>.env.json` 缓存，下次直接读，不再重复解码。
- `speech_level()` 按播放器当前位置取包络，嘴部小块纵向缩放 `1.0 → 1.32`；桌宠侧做低通，避免机关枪式抖动。
- TTS 缓存命中和新合成两条路径都已接 `speech=True`；音效预览/动作音效不触发口型。

## 实测

- `tools/verify_v325.py`：**24/24**。
  - 路由 5 种组合；连续 8h 衰减后饱食 42.4 / 水分 68.3；离线 8h 只结算 6h（饱食 56.8）。
  - 归零识别 both/hungry/thirsty；口渴时背包优先拿柠檬水。
  - 养成页 2 级 stack，默认 0、去打工 1、返回 0。
  - 默认皮肤 happy 用 267×512 脸补丁、有嘴部小块；sleep 保留整图（303×512）；JK 皮肤 happy 仍是 283×512 身体、有嘴块，JK sleep 不跳回女仆整图。
  - 真实播放：153 个 RMS 点，播放中最大口型强度 1.00。
- `tools/verify_v324.py`：动作导演回归 **26/26** 仍全过。

## 已知边界

- 脸补丁只覆盖默认女仆和 JK 皮肤；其他皮肤还没有对应锚点，强行贴会带女仆发丝。
- 口型强度来自真实 RMS，但解码是异步的，播放开头几十毫秒可能还没有包络；缓存后无此问题。
- 打工二级页的任务卡仍沿用原列表高度，任务多时二级页自身滚动。
- API 失败切本地是单向的一次兜底，不做“本地失败再回 API”的循环。
