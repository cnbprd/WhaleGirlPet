## 1. 背包自动取食

旧逻辑只有一个入口 `beg_snack()`：它会在临界/饥饿/口渴分支里翻背包，但受
`panel_open`、`task_active`、180/300s 冷却和随机概率影响。结果就是“背包里有东西，
人却不动”。

| 项 | 改动 |
|---|---|
| 新入口 | `Controller._auto_use_bag()`：启动后 2.2s 查一次，之后每 60s care tick 查一次 |
| 触发阈值 | 饱食 <55 或水分 <55；两项都低时优先能同时补的 |
| 选品 | 跳过玩具和营养为 0 的物品；只渴时只选有水分加成的，只饿时只选有饱食加成的 |
| 冷却 | 150s，吃完一份不会立刻连着吃第二份 |
| 场景 | 面板开着也照吃；打工中不打断，归零级仍走原有讨要链路 |
| 反馈 | 自动取食标记 `auto=True`，气泡显示“背包里的…吃掉了”，priority 1；`mute_idle=True` 时也会出声 |
| 诊断 | `runtime/auto_eat.log` 记每次检查的饱食/水分/任务状态和命中结果，超过 256KB 自动轮转 |

## 1.1 配置持久化修复（连带修）

排查自动取食时发现：运行中的养成/背包变化在磁盘上看不到。根因是 `_save_timer`
原本是一个 60s 周期定时器，却被 `save_config()` 用 `start(600)` 当成 600ms 防抖
定时器反复重启，`_flush_config()` 永远不执行，所有状态只在内存里，只有退出时才
落盘。现在拆成：

- `_save_timer`：`setSingleShot(True)`，任何改动 600ms 后合并写一次 `config.json`；
- `_autosave_timer`：独立 60s 周期，保证养成衰减/背包变化即使没有操作也会落盘。

这也解释了为什么之前“看背包数量没变化”：不是自动取食一定没执行，而是执行结果
还没写进磁盘；现在自动取食、手动喂食、打工状态都会按 600ms / 60s 正常落盘。

## 2. `anim.md` 第三阶段：分层 + 弹簧

### 资产

- 新增 `tools/make_secondary_layers.py`。
- 对 `default`、`jk` 两套皮肤生成裙摆 / 尾巴 alpha 层，1x + 2x，写
  `assets/skins/layers/layers.json`。
- 抠图口径：
  - 裙摆：手动多边形收在裙腰到裙摆下沿，颜色门只取深色布料 + 纯白荷叶边/围裙；
  - 尾巴：只取深色尾巴，不取同色系高光蓝发；
  - 尾巴层扣掉裙摆重叠区，避免同像素双画。
- 试过“底图挖洞 + 层补回”，旋转时裙腰会露出白缝；最终改为**底图保留完整立绘，
  层只覆盖可动区域**。静止时层与原图像素重合，动起来不会出现透明洞。

### 运行时

- 新增 `app/secondary.py`：
  - `AngularSpring`：半隐式欧拉，大 dt 自动拆子步，限幅防炸开；
  - `SecondaryMotion`：按皮肤加载 `skirt` / `tail`，窗口位移当惯性输入，镜像时取反；
  - 裙摆用“腰固定、越往下摆幅越大”的剪切形变；尾巴绕根部旋转；
  - 步态分支（walk/run/trot/skeletal/rig）回退完整整图，避免分层洞被切腿。
- `PetWindow` 接线：
  - 换肤 / 表情脸补丁 / 睡眠 / 动作整图 / 缩放都会同步重载层；
  - 1.2 倍以上自动换 `@2x` 层，缩回 1x；
  - 默认/JK 以外皮肤没有层资产，自动走旧平图，不报错。
