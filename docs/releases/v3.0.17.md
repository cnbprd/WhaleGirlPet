# 鲸鱼娘桌宠 v3.0.17：三档模型分工 + 包体瘦身与启动实测

这版只做两件事：把你说的「三个模型当一支团队」落成代码，把包体和启动的实测数字摊开。

## 一、三档分工：真的会换模型，不是写在配置里好看

`ServerManager` 新增两个方法（`app/local_llm.py`）：

- `role_model(role)`：`config["model_roles"]` 里的文件名 → `resolve_model()` 解析成真实 gguf 路径。
- `ensure_role(role)`：已经在跑的就是目标模型且 `health()` 正常 → **直接返回，不重启**；否则加锁停掉再起。
  可用内存 < 目标体积 × 1.15 → **不切**，写 `fallback_note`，用当前模型照常回答。宁慢不死。

`LocalChatWorker` 加了 `role` 参数（`brain` / `fast` / `tool`），`Controller._chat_plain` 按
`_looks_like_code()` 选档，技能路由固定 `tool`（本来就是结构化 JSON 输出）。

默认配置（`F:\WhaleGirlPetApp\config.json`）：

```json
"model_roles": {
  "brain": "qwen35-4b-Q4_K_M.gguf",
  "tool":  "deepseek-coder-6.7b-instruct.gguf",
  "fast":  ""
}
```

**真机实测**（`tools/live_roles.py`，ctx 4096，同一句"只回复两个字：在的"）：

| 动作 | 切换耗时 | 单轮响应 |
| :-- | --: | --: |
| 起 brain（4B，2525.9 MB） | 5.8 s | 1.3 s |
| brain → tool（6.7B，3650.5 MB） | **23.6 s** | 6.5 s |
| tool → brain | 6.9 s | 1.6 s |

引擎是单进程单模型（`-np 1`），换角色 = 重启引擎，所以"三个模型常驻"不成立（三份权重合计 9.2 GB）。

代价这么大，做了两个配套：

1. `_looks_like_code` 收紧：去掉「异常」「bug」「脚本」这类日常词，只留「报错 / traceback / 这段代码 / 代码 / 函数 / 编译 / 正则 / 写个脚本 / 重构 / 单元测试 / pandas / numpy / SQL」。误判一次就是 23.6 s。
2. 走 `tool` 前先出气泡："我要把专写代码的那个脑子叫醒，得等十几二十秒…"。不然用户会以为程序卡死。

不要这个代价 → 把 `tool` 改成 `""`，全部走 4B。

## 二、「Gemma 4 E2B = 多模态快反」这条，本机缺一块零件

- `runtime\models` 下 `*mmproj*` 文件数 = **0**。多模态依赖视觉投影权重，没有它，`gemma4-e2b-it.gguf` 只能跑纯文本，看不了截图、听不了语音。
- 它体积 3269.1 MB，比大脑 `qwen35-4b` 的 2525.9 MB **还大 743 MB**，当"快反"不会更快。
- 所以 `fast` 默认留空。想看图只能走云端多模态（v3.0.15 的三协议接入已就位，但 `ChatWorker` 目前只发文本 messages，没做图片编码）。

补齐 `mmproj-*.gguf` 之后把 `fast` 填上即可，引擎侧不用再改。

## 三、包体瘦身与启动（实测）

| 指标 | v3.0.16 基线 | v3.0.17 | 变化 |
| :-- | --: | --: | --: |
| exe 体积（onefile） | 69.4 MB | **64.0 MB** | −5.4 MB（−7.8%） |
| 解包 + 主进程起来 | 4.26 s | **2.10 s** | **−2.16 s** |
| 常驻 RSS（双进程合计） | 171 MB | 175 MB | +4 MB（噪声内） |

改的地方：`hiddenimports` 删 `tkinter`（原生 Tk Splash 早在 v3.0.1 就删了，留着白拖 tcl90/tk90）；
删 `collect_all('tabulate')`（app 下 0 次 import）；`excludes` 加 `numpy/pandas/scipy/matplotlib/PIL/pytest/tkinter`；
`optimize=2`（全项目 0 处用 `__doc__`）。`build.ps1` 同步。

启动还剩 2.1 s 花在 onefile 解包（先把 64 MB 解到 `%TEMP%` 再执行）。改 onedir 能省掉这段，但要同步改 iss 文件清单、portable zip 和更新器 —— 发布形态变更，本版没动，等你拍板。

## 四、"WhaleGirlPet 是项目家族、该抄 vlln/whale-girl"这条：核实结论

`vlln/whale-girl` 真实存在（npm `whale-girl` 0.2.4、`whale-girl-desktop` 0.1.0，MIT，Node 引擎 + Tauri 壳，`--headless` 只跑心跳与 SSE，默认连本地 DSH 3080）。但它是 **DSH Web GUI 的插件/桌面壳**，与本项目（Python + PySide6 独立进程）不是同一家族，"项目家族"的说法不成立。

可借的架构思想我们其实已经是那个形状：

| 对方 | 我们 |
| :-- | :-- |
| Node 引擎（状态轮询 / 事件消费） | `Controller` + QTimer 心跳 + `scheduler` |
| Tauri 渲染壳 | `pet_window.py`（只负责画与动画） |
| SSE 事件 | Qt Signal / `do_action` / `anim_engine` 事件点 |
| `--headless` | 对桌宠无意义（它就是给眼睛看的） |

本版没有再照搬其技术栈，只守住"引擎不依赖渲染层"这条（`local_llm` / `memory_tiers` / `skeletal` 都不 import `pet_window`）。
