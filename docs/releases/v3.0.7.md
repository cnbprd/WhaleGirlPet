## v3.0.7

这一版修的是「模型扫不到 / 扫到也不说话」和「联网能力换台电脑就废」，外加把浏览器和搜索源都铺开。

### 1. 把模型粘到数据目录也不认（现在认了）

旧版只扫一个固定位置：程序目录的 `runtime\models`。装在 `C:\Program Files` 或把模型放到「储存位置」（数据目录）下，就永远扫不到——你把它丢进 `F:\WhaleGirlPetApp\workspace` 正是这种情况。

现在会按优先级扫这几个目录，每个再向下找两层：

```
<程序目录>\runtime\models
<数据目录>\runtime\models
<数据目录>\models
<数据目录>\workspace
<数据目录>\workspace\models
+ 你在面板里手动加的任意文件夹
```

识别方式也不只看后缀：`GGUF` 四字节魔数能认出来，所以 Ollama 那种没有扩展名的 blobs 也算；小于 1MB 的占位文件直接排除（你 workspace 里那三个目录就是这种情况，见下面第 3 条）。

面板「自定义模型」页同步改了：
- 列表里每条后面直接标出它在哪个目录；
- 鼠标悬停「当前模型」那一行，能看到全部搜索目录；
- 新增「添加模型文件夹」按钮，任意盘都能加进来；
- 下载落地改成数据目录（装在 Program Files 时原来写不进去）。

实测：本机扫出 6 个 gguf（去掉了程序目录与数据目录里的同名副本），默认取 `qwen35-4b-Q4_K_M.gguf`；引擎加载一个 833MB 模型 6.2 秒成功，health 正常，对话有回复。

### 2. 真正的原因：Ollama 是「假活的」

这台机器上 Ollama 正在跑（11434 通），`/api/tags` 也能列出 `gemma4-e2b:latest`、`qwen3.5:4b`、`deepseek-coder:6.7b-instruct`，但**一旦真的生成就报错**：

```
HTTP 500  error starting llama-server: llama-server binary not found
(checked: C:\Users\...\Programs\Ollama\lib\ollama\llama-server.exe)
```

也就是 Ollama 自己的推理程序丢了。旧版遇到这种情况：

- 配置里只要写过 `ollama` 就会被强制当成 Ollama 后端，`ollama_broken` 标记被忽略；
- 请求全打到 11434，于是 `/v1/chat/completions` 回 404，看起来就是「模型在、但不启用」。

现在：

| 改动 | 效果 |
|---|---|
| `backend` 里 Ollama 坏过就退回 `dafeiyu_cpp` | 实测：强制 ollama 的配置，第一次 500 后自动用自带引擎，17.5 秒后正常答出「你好」 |
| 任何 4xx/5xx 都记病因并回退（原来只处理 5xx） | `last_error` 里能看到 `llama-server binary not found` 原文 |
| Ollama 坏过一次后本进程不再重试 | 不会每次聊天都白等一轮 |
| 模型页顶部新增「Ollama 里的模型」段 | 3 个模型都列出来，可一键「使用此模型」切到 Ollama |
| 新增按钮「检查 Ollama 能否真正生成」 | 实测文案：`✘ Ollama 自己坏了：找不到 llama-server.exe（HTTP 500）。重装 Ollama 就好，这期间桌宠会自动用自带引擎。` |

> 想彻底修好 Ollama：重装 Ollama 即可。不修也没关系，桌宠会走 `runtime\models` 里的 gguf。

### 3. 你粘过来的那三个目录是空壳

`F:\WhaleGirlPetApp\workspace\` 下是 `deepseek-coder\6.7b-instruct`、`gemma4-e2b\latest`、`qwen3.5\4b` 三个文件，**每个 0 字节**——这是 Ollama 的 manifest 标签文件，不是权重。真正的权重在 Ollama 的 blobs 目录里。复制这几个标签过去等于什么都没复制。

要用哪个就把真正的 `.gguf` 拷进上面任一目录（或者直接用 Ollama，前提是它修好）。

### 4. 联网搜索：从 1 个源变成 3 个

原来只抓 Bing 一家。现在按顺序问，凑不够结果就换下一家，自动去重：

| 源 | 实测 |
|---|---|
| Bing 国内版 | 10 条，0.4 秒 |
| 百度 | 9 条（标题可直接用，摘要部分版本有部分没有） |
| 360 搜索 | 7 条（标题+摘要都能取到） |
| DuckDuckGo | 本机网络超时，未启用 |

搜「郑州 明天 天气」：Bing 拿 4 条（去重后）→ 自动补百度 1 条，共 5 条，2.2 秒。顺带修了摘要里 `&ensp;`、`&#0183;` 这类 HTML 实体没解码的问题（现在统一 `html.unescape`）。

### 5. 浏览器：不再只认 Tabbit 一个

旧版硬编码了 `D:\Tabbit Browser\...` 一条路径，别人装 Chrome / Edge / 360 / QQ 浏览器就一个都找不到，只能退回系统默认浏览器。

现在按三级探测，去重后按「默认浏览器优先」排序：

1. 注册表 `UrlAssociations\http\UserChoice` → 系统当前默认浏览器；
2. 注册表 `App Paths`（chrome / msedge / firefox / brave / opera / vivaldi / 360se / 360Chrome / QQBrowser / sogouexplorer / 2345Explorer / Tabbit）；
3. 常见安装路径兜底（Program Files、LocalAppData 各家族）。

打开方式按浏览器家族给参数：Chromium 系 `--new-window`、Firefox `-new-window`、其它直接丢 URL；都失败才交给 `QDesktopServices`（系统默认浏览器一定能开）。

实测本机探测出 2 个：`Edge（chromium）`、`Tabbit（chromium）`，首选默认浏览器 Edge。
