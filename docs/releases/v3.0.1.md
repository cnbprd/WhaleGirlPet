## v3.0.1

这一版按用户逐条提的九条意见重做，另外补了三条数值/体验上的收尾。

### 启动画面
- **启动画面改成「纯人物在动」**：参考 Windows 开机动画的思路——屏幕上不要任何背景板，只看到大肥鱼本人，并且她自己在动。删掉了原来那张带深色底的启动图（PyInstaller 的 Tk 窗口只能贴不透明方块图，做不出透明背景），改为 380×580 的透明浮层，只画人物：呼吸（纵向 ±3.2%、横向 ∓1.8%）、水中浮沉（上下 ±9px）、左右漂移（±8px）、倾身（以脚底为轴 ±1.8°）四层叠加。没有渐变、光晕、涟漪、气泡、文字、地面投影。
- **代价**：单文件版冷启动有约 3 秒完全没有窗口（解压自身 78MB），这段时间只有任务栏图标。实测 2.2 秒时屏幕中央还是空的，4.8 秒时人已浮在桌面上。

### 菜单与窗口
- **托盘去掉「搜索剪贴板内容」**。
- **去掉重复的「隐藏桌宠」**，只留「显示 / 隐藏桌宠（Alt+Shift+F）」。
- **右键「陪我聊聊天」并入「设置 → 聊天」页**。
- **设置窗口可以自由缩放**：加了右下角拖拽抓手，最小 520×560，实测缩到 520×620 正常。

### 养成数值
- **名字只在编辑时出现**：平时只显示「名字：大肥鱼」+「修改」，点修改才露出输入框，保存后收起。
- **饱食 / 水分 / 心情重做**：饱食 0.30/分（约 5.5 小时见底），睡着只算 35%；水分严格按「比饱食低 40%」= 饱食的 60%；心情要有 25 分钟无沟通无互动才开始掉，睡觉暂停。取消了原来「低饱食连带掉心情」的逻辑。
- **动作分级消耗**：走路 1.2/0.7、跑步 4.0/2.4、跳舞 2.4/1.4、蹦跳 0.6/0.35、被捏 0.3/0.2、看书 3.0/1.8、满屏跑 6.0/3.6、摸鱼 1.0/0.6、清理 5.0/3.0、擦桌面 4.0/2.4、做家务 6.0/3.6、玩耍 3.0/1.8（饱食/水分）。
- **亲密度**：抚摸 1.0（日限 40）、聊天 1.0（20）、喂食 1.0（6）、喜好食物 2.0（4）、玩耍 3.0（3）、买玩具 5.0（1）、喝水 0.5（4）；超上限按两折。分级：80 挚友 / 60 亲密 / 40 朋友 / 20 熟悉 / 0 陌生。
- **首次启动给一次新人礼包**：饱食 / 水分 / 心情低于 70 的抬到 70，只发一次（存档 `gift_v3` 标记），之后再饿到 0 不会偷偷复活。

### 玩法
- **玩具货架**：毛线球 24 金币、逗猫棒 30、泡泡机 36、小黄鸭泳圈 42。**玩一次消耗掉一个**（一次性消耗品），玩完语音会报剩余数量。
- **打工任务真正有动作**：五个工种各自持续表演——看书（前倾点头 + 书）、摸鱼（慢晃 + 泡泡）、清理（左右大幅摆 + 扫帚）、擦桌面（高频画圈 + 抹布）、做家务（抱箱前移 + 纸箱），道具全部用 QPainter 代码绘制，不再 4.2 秒后回 idle 空转。

### 界面与聊天
- **番茄钟并入「日常提醒」**：专注计时 25/45/60/停止 与喝水/久坐/音效勾选同组；「定时任务」列表与「昨天使用情况」改为可伸缩，整页铺满无底部空白。
- **聊天不再发两遍**：原来面板自己 append 一次、控制器又 append 一次，现在统一由控制器挂气泡。
- **聊天不再卡顿**：`_system_text()` 里同步联网那段（urllib 15 秒超时，跑在主线程）整段删除，改走已有异步线程。
- **气泡长句不再被裁**：改为最大宽度 + QLabel 自动换行 + `heightForWidth` 手算行高；清屏与货架切换改成「先摘父再 deleteLater」，不再出现两个气泡/按钮叠在一起。

### 已知不足
- 启动那 3 秒空白是「纯人物透明」的代价，暂未做文件夹版（onedir）对比方案。
- 打工动作是程序化摆动 + 代码道具，还没有同一套皮肤的逐帧序列帧。
- 玩具只做了「玩一次消耗一个」，没有耐久/磨损表现。
