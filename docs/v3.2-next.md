# v3.2 后续路线：intensity 曲线、gaze/body lean、ASR

日期：2026-11-27  
状态：**intensity 曲线、gaze/body lean、ASR 单句输入已完成并实测。** ASR 只做显式一次录音的离线 SAPI 输入层，不是常驻监听，也没做口型同步。

## 现有协议入口

- `docs/3d-emotion-bus.md`：情绪消息/优先级/回落/姿态字段
- `docs/3d-transition.md`：换模过渡与逐步验收

## 1. intensity 曲线

目标：情绪强度不要单帧跳变，进/出有短包络；渲染侧只消费归一化强度，不反向依赖业务语义。

**已完成（2026-11-27）**：

- 协议字段落地为 `curve: {"attack_ms": 180, "release_ms": 420}`，两个字段都可选，缺省 180 / 420 ms，夹在 40–2000 ms。
- 草案里的 `hold_ms` 没有实现：保持期由 Python 侧 `P_USER/P_LLM/P_AUTO` 的 TTL 和 TTS 播放期延长负责，渲染侧再加固定 hold 会叠两层。
- `emotionCurrent` 按 `dt / duration` 线性逼近目标；`draw()` 用 neutral 帧 0 与 smile 帧 2 按 `emotionCurrent` 混合。强度 0.8 是 80% 的笑，不是二值切脸。
- 自动眨眼优先于情绪混合；强度回到 0 时清 `emotionActive`，不残留覆盖。

验收结果：

- 0→0.8：trace 反推约 **182 ms**（设定 180 ms）。
- 0.8→0：trace 反推约 **353 ms**（满程 420 ms 的 80% 应为 336 ms，差值来自 34 ms 采样间隔）。
- 60 ms 中间帧与 neutral / happy 的全窗 RGB 平均差分别为 **0.117 / 0.414**，说明不是硬切。
- `tools/test_emotion_bridge.py` 8/8 通过，新增 `curve` payload 断言。
- 产物：`docs/_3d_emotion_neutral.png`、`_crossfade.png`、`_happy.png`、`_release.png`、`_after.png`；step 4 exe **1,324,544 B**，SHA256 `5D909D8B2F82BB65AF8966F623C0BFEFA18E86DF07D5F300D8E828DE24345119`。

正常动画长跑（2026-11-27，`3d/tools/emotion_longrun.py`）：

- 11g 起默认 **10 分钟**，`WHALE3D_FACE=auto`、`WHALE3D_CLIP=idle`，20 秒一轮 `happy 0.8 + gaze` → `lean` → 空包回正；每 10 秒采 RSS/CPU，并在中段/结束截图。
- 旧 90 秒基线（历史）：`alive_after_90s=True`；动画前后帧平均差 **0.284**；RSS **67.5 MB** 稳定；CPU **33.4–36.9%**；FPS **25.4–28.9**，平均 **27.76**。
- 10 分钟结果：`duration_s=600`、`alive_after_soak=True`；动画帧差 **0.284**；RSS 起 **67.6 MB** / 止 **67.8 MB**（全样本 67.2–67.9）；CPU 平均 **35.4%** / 峰值 **38.5%**；FPS 最低 **19.7** / 最高 **28.9** / 平均 **27.68**（最低值出现在启动截图窗口，不是稳定段中位）。截图 `docs/_3d_longrun_anim_a.png`、`_anim_b.png`、`_3d_longrun_10m_mid.png`、`_3d_longrun_final.png`。
- 这只是 10 分钟 bounded soak，不是 24 小时内存泄漏结论；RSS 只波动 0.7 MB，不能外推成“永不泄漏”。

## 2. gaze / body lean

目标：让视线和身体倾斜变成“可选表现层”，不是每帧强制 IK；没有目标时回正。

**已完成（2026-11-27）**：

```json
{"gaze": {"x": 0.8, "y": -0.1, "weight": 1.0},
 "lean": {"x": 0.8, "y": 0.0, "weight": 0.8}}
```

- `EmotionBus::Frame` 增加 `gazeX/gazeY/gazeWeight`、`leanX/leanY/leanWeight`；嵌套对象存在但缺 `weight` 默认 1.0，对象完全缺失 weight=0；`x/y` 夹 [-1,1]，weight 夹 [0,1]。
- `Model::applyGazeLean()` 只存目标；新增 `gaze*/lean*Current` 与 `updatePose(dt)`：180 ms attack / 420 ms release 线性逼近，`applyPoseOffsets()` / `applyPoseOffsetsSelf()` 只使用 current 值。
- `applyPoseOffsets()` 在 ozz `SamplingJob` 后、`LocalToModelJob` 前改 head/neck/spine/chest 的局部四元数；`applyPoseOffsetsSelf()` 在自研采样后、`computeGlobals()` 前改节点旋转。
- 骨骼映射从 `buildOzz()` 记录：`head=5 neck=4 spine=2 chest=3`。gaze 最大 yaw 0.38 rad、pitch 0.26 rad，neck 35% / head 65%；lean 最大 roll 0.18 rad、pitch 0.12 rad，spine/chest 各 50%。
- 不带 `gaze`/`lean` 的新包 weight=0，空包会把目标清零，current 再按 release 包络回正；`WHALE3D_POSE_TRACE=1` 每 100 ms 打印 6 个 current 值。
- `3d/tools/pose_accept.py` 冻结动画、默认 `WHALE3D_SPRING=0` 隔离头发/尾巴次级弹簧，抓 neutral / 60 ms / 满值 / release / reset / 3 s；`send_emotion.py` 增加 `--gaze-*` / `--lean-*` 参数。

验收结果：

- 默认 ozz，`WHALE3D_SPRING=0` 隔离头发/尾巴次级弹簧：neutral→gaze 60 ms **0.164** / 满值 **0.712**；lean 基线→lean 60 ms **0.310** / 满值 **1.174**；lean→release 120 ms **0.758** / 200 ms **1.051**；空 pose 后 neutral→reset **0.000**、3 s **0.000**。
- 默认弹簧（`WHALE3D_SPRING=1`）对照：`PoseTrace` 的 gaze/lean 六个 current 全为 0，但 neutral→reset 仍有 **0.4–0.8**（随弹簧相位变化；本轮 **0.413**（1 s）/ **0.707**（3 s），另次 **0.817 / 0.572**），reset→reset 3 s **0.785**；残差来自 SpringBone 独立摆动相位，不是姿态值没归零。pose 层截图因此默认关弹簧。
- 旧的默认 spring 首版数值（0.948 / 1.600 / 0.641）只保留为历史基线；self 路径旧值 0.809 / 1.336 / 0.648 未在本轮重新跑平滑验收，不能当作新构建结论。
- 日志 `Pose bones: head=5 neck=4 spine=2 chest=3`；截图 `docs/_3d_pose_neutral.png`、`_gaze_60ms.png`、`_gaze.png`、`_lean_base.png`、`_lean_60ms.png`、`_lean.png`、`_release_120ms.png`、`_release_200ms.png`、`_reset.png`、`_reset_3s.png`；spring-on 对照 `_neutral_spring.png`、`_reset_spring.png`。

限制：`gaze` 只转 head/neck 骨，没有眼骨或 BlendShape，视觉上接近“转头”而不是严格“转眼”；pose 有 180/420 ms 包络，但不是眼动级 IK；默认弹簧下 reset 的整窗残差来自头发/尾巴 SpringBone 相位，pose 层本身用 `WHALE3D_SPRING=0` 实测为 0.000；10 分钟 soak 只覆盖 idle + 自动眨眼 + 周期姿态，不是 24 小时。

## 3. ASR

目标：语音转写是**输入层**，不塞进渲染循环；识别结果走文本/情绪事件，渲染侧只收结果。

**已完成（2026-11-27）**：

- 新增 `app/asr_service.py`：默认关闭，构造后不创建录音线程；只有按钮/热键显式 `arm_once()` 后才 `listen()` 一次。识别结束自动回到关闭态，不做常驻监听。
- 后端仍是 `app/voice_cmd.py` 的 Windows 离线 SAPI（`System.Speech`），不引入外部模型、不上传音频。
- `main.voice_listen()` 改为走 `AsrService`；结果仍由 `_on_voice()` 接住，命中唤醒词/本地命令后走原 `send_chat()`，再由 `emotion_bridge.user_text()` 进入情绪桥。
- SAPI 听写在静音/环境噪声下会吐低置信度假词（实测一次噪声被识别成“阿丽阿娜”，`conf=0.16`）。`voice_cmd.recognize()` 增加 `min_conf=0.30`：低于阈值返回 `ok=False / text="" / reason="low_conf"`，不把噪声拼成用户输入；`_on_voice()` 对应提示“置信度太低，没敢当成指令”。
- 验收产物：
  - `tools/test_asr.py`：默认关闭不创建 worker；SAPI 合成“打开面板”识别回“打开面板”（`conf=0.377`）；静音失败返回 `no_speech`；低置信度假词不再产出文本；服务成功后自动关闭。
  - `build/test_asr_ui.py`：Controller 启动时 `asr.enabled=False`；成功文本 `打开面板` 进入 chat；失败结果不产生聊天文本；手动触发会 `arm_once()`。
  - `3d/tools/asr_accept.py`：识别“别难过，笑一个”（实际文本“别难过小一个”，`conf=0.494`）→ `EmotionBridge.user_text` 出 `P_USER happy 0.9` → 真实 3D 窗口全窗 RGB 差 **0.541**；截图 `docs/_3d_asr_neutral.png`、`_3d_asr_happy.png`。
  - 限制：只验证单句 SAPI + 一次显式录音；不是连续/流式 ASR，没有声学模型准确率结论，也没有做音素级口型同步。阈值 0.30 是本机短句实测值，换麦克风/环境需要复测。

## 顺序与门

1. intensity 曲线（done：协议 + 线性包络 + 真实窗口采样）
2. gaze/body lean（done：可选表现层 + 双采样路径 + 180/420 ms 平滑 + 10 分钟 soak 叠加）
3. ASR（done：单句 SAPI 输入层 + 默认关闭 + 置信度门槛 + 真实 3D 表情验收；连续识别/口型未做）

每步都要有：单元测试或可复现脚本、真实窗口截图/采样、失败回退。没有这三样就不算完成。

## 本轮明确未做

- 没有新增 3D 网格、骨骼、表情资源或渲染管线；姿态层只复用现有 head/neck/spine/chest。
- ASR 只做显式一次录音的单句输入，不做连续监听/流式识别，也没有音素级口型同步；不宣称声学模型准确率。
- pose 有 180/420 ms 平滑/回正包络，但仍没有眼骨/BlendShape；默认弹簧的 reset 残差已用 spring-off 对照归因，不是 pose 未归零。
- 没有重打 v3.2 的 ZIP / 安装包；当前只是 dev exe。
- 不把“计划存在”说成“功能完成”；长跑只到 10 分钟，不宣称 24 小时无泄漏。
