## 配套防守卡

`app/security_cards.py` 有 13 张卡，其中“反扒经验”覆盖：

- 木马：持久化 + 外联信号
- Rootkit：驱动、服务、启动链异常
- 注入：输入越界、错误回显、权限过大
- Kali：扫描/枚举留下的流量和日志痕迹
- DDoS：带宽洪峰、半连接、限流与清洗
- 钓鱼/弱口令：域名核对、多因素、口令不复用

每张卡只写“看什么信号、怎么防、依据”，不写攻击步骤。
