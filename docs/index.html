透明、置顶、可点击穿透。会走、会打工、会聊天；不是只会漂浮的动图，而是一个本地优先的桌面搭子。

下载安装包 便携包 / 校验值 查看源码
真实 3D 窗口运行录屏；背景为演示用深色底，非桌面实拍。

现在能做什么

透明 3D 壳

420×620、OpenGL 3.3；窗口透明、置顶、可拖拽，模型区域可点，卡面区域外点击穿透。

17 张表情 / 动作卡

独立透明 overlay 绘制；通过本机 UDP 触发，不撑大主窗口的可点击区域。

本地优先

账号、聊天、记忆、TTS 缓存默认跟安装文件放在一起；安装目录不可写才回退 AppData，可离线。

早期但可跑

3D 渲染、VRM、SpringBone、无头回归已落地；聊天/ASR/TTS 还在从 2D 迁移。
